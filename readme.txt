Talent Sphere - HR Consultancy Website
====================================

Description:
------------
Talent Sphere is a modern HR consultancy website designed to showcase staffing and recruitment services. The website features a clean, professional design with sections for company information, services, and contact details.

Features:
---------
- Modern and responsive design
- Smooth scrolling navigation
- Interactive service showcase
- Contact form for inquiries
- Mobile-friendly layout
- Professional color scheme

Sections:
---------
1. Introduction
   - Company overview
   - Key services

2. About Us
   - Company vision
   - Mission statement
   - Core competencies

3. Services
   - Temporary Staffing
   - Permanent Staffing
   - Sector-specific solutions
   - Executive Search

4. Contact
   - Contact form
   - Company information
   - Social media links

Technical Details:
----------------
- Built with HTML5 and CSS3
- Responsive design
- Modern UI components
- Optimized for performance
